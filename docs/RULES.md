# 通常詰将棋としての検証範囲

9×9、通常の駒数。攻方玉は任意で、無い場合に補充・配置しない。玉方玉は必須。盤面と攻方持駒以外の非玉の駒は玉方持駒として明示する。

攻方は連続王手で最短の詰みを選び、玉方は不詰を優先し、詰む場合は最長になる応手を選ぶ。二歩、打歩詰、行き所のない駒、王手放置を禁止。自玉があるときのみ自玉への王手を解消する条件が加わる。詰上り、持駒の使い切り、余詰、無駄合も別々に検証する。

現在の復元探索は、二つのライブラリによる個々の合法手・連続王手と、選んだ経路の同一状態4回出現を検査するもの。これは通常詰将棋の完全な規約検証ではない。無駄合・復元型無駄合や、詰将棋側の反復規約の差（同一局面2回で失敗とする規定もある）は未実装。反復回数だけで長さを稼いだものを通常詰将棋の成果として扱わない。

復元しつつ持駒だけを増やす経路も、通常詰将棋で有効な趣向か無駄合かを確認するまでは部品実験に留める。旧ログの`valid`はこの限定的な経路検査の合格であり、作品完成を意味しない。

記録候補に必要な証拠：全玉方応手に対する詰み、全攻方王手に対する早詰排除、1525手を超える最短詰手数、使い切りと余詰の確認、合駒・反復規約の確認。エンジンNoMate報告や長い選択経路だけでは満たさない。
