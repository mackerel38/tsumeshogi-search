# 龍の往復と歩二枚を使う内側部品（015）

盤上は攻方龍22・馬44、玉方玉14・角47の四枚。攻方持歩二枚、残りの駒は玉方持駒。自玉なし。

手順：▲15歩 △同玉 ▲26龍 △14玉 ▲15歩 △13玉 ▲22龍まで。

全玉方応手を含む7手以内詰の戦略と、全攻方王手を含む5手以内詰の排除を、異なるライブラリで独立検証した。上限の玉方応手は全て一通り。下限は玉の移動・盤上捕獲だけを選ぶ戦略で、無駄合に依存しない。最短7手の部品であり、長編作品の完成や余詰検査完了を意味しない。

## 各駒の役割

- 龍22は玉の逃げ道を制限し、26へ往復する。26に来ることで二度目の15歩を玉が取れなくなる。
- 馬44は26を守り、玉が26龍を取る応手を防ぐ。
- 玉方角47は、馬26から25馬で早く詰ませる経路に対して、25角と馬を取れる位置にある。
- 最初の歩は玉に取られ、二枚目の歩は15に残って14への逃げを防ぐ。

## 一巡後の状態と未成立の接続

龍は22へ戻る。馬44・玉方角47は変わらない。玉は14から13へ移り、攻方持歩二枚のうち一枚は玉方持駒、もう一枚は攻方15歩になる。その局面で既に詰むため、現状では次の巡回を始められない。

復元では龍・馬だけの位置一致を目標にせず、玉の位置、15歩の処理、次の持歩、早い収束の禁止を同時に満たす必要がある。歩一枚での不詰はエンジン報告だけでは証明とせず、別途検証する。反復可能性は未証明。

`upper-proof-dag.json` が全応手の詰み証明、`lower-proof.json` が5手以内詰の排除、`proof-status.json` が検証範囲。既存作品の盤面を使ったものではなく、014の導入部分と不要になった桂を取り除いて得た。
