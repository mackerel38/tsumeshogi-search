# 金の捕獲と消費を含む7手の部品011

初形は馬34・角54・桂13・桂45、玉方玉11・歩22・金43。攻方持駒なし、自玉なし。
余り駒はすべて玉方持駒。既存作品の盤面は読んでいない。

選択手順：▲21桂成 △同玉 ▲43角成 △32歩打 ▲33桂不成 △11玉 ▲12金打。
盤上の金43を取得し、最後に金を打って使う。32の合駒を取らずに桂で王手するため、余計な持駒を増やさない。

7手以内詰は玉方の全合法応手を含む14詰上りを二種類のライブラリで独立検証した。すべて攻方持駒なし、同一局面の反復なし。5手以内の早詰は全攻方王手を含む36局面の証明で排除した。下限戦略の合駒は32歩打の2局面だけで、王手駒がその歩を取ると玉が王手駒を取れることを両ライブラリで確認した。有効な防御として取り扱う。

最短7手の部品である。余詰・成不成の非限定を含む作品としての完全性は未証明。角の金捕獲時の成・不成も検討対象。長い往復と内側のリセットはまだ作れていない。010への馬の復帰を実現したものではない。

金43は取得対象であると同時に、角54の利きを遮り、初手21桂成の直後に玉が桂を取れるようにする役割を持つ。金を単に除去した比較図は利きまで変わり、1手の早詰になるので「金なしでも同じ入口」の比較には使わない。

歩22を除去した012は、生の合法手ゲームで最短9手を検証したが、詰み証明24枝中5枝に攻方持駒が余る。選択9手だけは使い切るものの、完成作品とは扱わない。
